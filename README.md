# TechFlow WebPage Front-End Devleopment




## QUICK NOTE:

This website was created solely for the purpose of practicing and improving my front-end development skills. It is not a real or commercial website. The project was originally based on the N212 Intermediate Front-End Development class of one of the homeworks, and I expanded upon the original design and functionality to further develop my skills and explore my own ideas. 


## TechFlow

TechFlow is a responsive website project designed to present a modern technology platform. The project includes a home page, features page, and an About page with information about the company, its values, story, and achievements, and many more to come.


## How to Run

    1. Download or clone the project.

    2. Open the homework_two folder.

    3. Open index.html in a web browser.

    4. Use the navigation menu to visit the Features and About pages.

No server or additional software is required.


## Design

 The TechFlow website uses a clean, modern technology-focused design. The About page uses a more editorial layout with larger visual sections, a dark values section, company statistics, and a prominent call-to-action to distinguish it from the other pages.
